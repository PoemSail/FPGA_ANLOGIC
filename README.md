# 芯驿·智慧公交站 第9版

FPGA 在宣传和乘客服务界面之间切换，并提供视频、照片、候车音乐与频谱显示。本仓库对应 `Station_MusicFix_PIRDiag_20261102.bit` 的工程源码。

## 红外触发与页面切换

系统已实现红外自动切换逻辑。传感器 OUT 通过 P1-8 接入 FPGA C11，上电预热 60 秒。预热结束后，输入先低至少 100 ms，再高至少 50 ms，系统便在帧边界切到乘客服务。最后一次有效触发后，20 秒没有新事件就返回宣传。持续高电平只计一次。演示可从普通宣传页开始，等传感器回到低电平后从前方横向走过。

板载 D6 对应的灯显示 FPGA 采样到的 C11 电平，高亮低灭。人工切换可使用矩阵 A 或板载 C5 长按约 1 秒。

## 工程复现

使用 Tang Dynasty 6.2.168116 打开 `project/Station_Board_Keypad_Final.al`，目标器件为 EG4S20BG256。克隆后，将 AL 根节点的 Path 改为本机 project 目录的英文绝对路径。工程约束位于 project/src，原始文件校验值见 source_manifest.json。
